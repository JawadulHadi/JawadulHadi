# Privacy and limits

## Privacy

- The owner access code and GitHub credentials stay on the server and are never sent to the AI.
- Pasted code is used for one request and is not stored.
- Only public data is collected from GitLab, Bitbucket, npm and PyPI.

## Limits

- Each draft and report uses AI credits, so the studio is not unlimited or free to run.
- Public sources have rate limits. When a limit is reached, that source is marked unavailable.
- Private GitLab and Bitbucket repositories are not supported yet.
- GitHub Wiki pages and the social preview image must be added by hand.
