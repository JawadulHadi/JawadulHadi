# README Studio overview

README Studio is a private workspace for writing accurate repository documentation and short code reports. Everything is behind an owner access code.

## What it does

- **README drafting**: turns a description and an existing README into a polished README.
- **Code report**: collects verified public facts about a repository or package, then adds a short AI interpretation.
- **Publish to GitHub**: writes the README, docs pages, a banner and logo, the description, topics, a tag and a Release to a repository, then re-reads it to confirm the result.

## Principles

- Facts come from sources, and every fact links back to where it came from.
- AI interpretation is labelled and kept separate from facts.
- Nothing is invented. Missing information is marked, not guessed.
- Generated content is identity-neutral. The example owner, `alex-morgan-demo`, is fictional.
